# ИИ в работе — митап РАЗУМ

Интерактивная презентация для внутреннего митапа департамента ИТ ДК РАЗУМ.

**Тема:** год прогресса ИИ, личный опыт успехов и провалов, MCP, агенты vs чат-боты, архитектура.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:3030 — слайды с интерактивной навигацией.

## Править на лету

Слайды в `slides.md` (Markdown + Slidev). Можно редактировать прямо во время показа — изменения применяются мгновенно.

## Сборка

```bash
npm run build    # → dist/
```

Деплой на GitHub Pages — автоматический при пуше в main.
